# 변경 기록

## 2026-11-21 유지관리 정리
- 관리자 인라인 코드를 기능별 10개 파일과 CSS로 분리. 기존 전역 API 유지.
- 인증 시작을 마지막 파일로 이동해 분리 파일 로딩 중 초기화되지 않도록 수정.
- 과거 관리자 복제본 2개를 최신 화면 연결문으로 축소.
- npm 설치목록·잠금파일·정적 검사·GitHub Actions 추가.
- VM 테스트가 실제 HTML 순서로 기능 파일을 읽도록 수정.
- preview에 CSS/JS를 포함하여 독립 실행 시 로컬 파일 누락을 해결.
- 설정 화면의 오래된 생산관리 안내 갱신.
- 주문·재고·사진 데이터, DB 스키마, Apps Script 배포 변경 없음.

## 2026-11-21 — 재고 관리 첫 사용 화면
- 입고·실사·추가 작업 가능 수량을 첫 화면에 배치하고, 재고 확인·생산계획·변경 이력을 분리. 작은 화면에서는 재고 목록을 카드로 표시.
- 품목 설정·레시피·엑셀은 접어서 표시. 입고는 추가분, 실사는 전체 수량임을 구분. 기존 계산, 저장 규칙, 주문/재고 연결은 변경 없음.
- 가짜 품목으로 바로가기, 이동 후 기록 방식, 390px 배치 및 기존 생산 기록 흐름을 브라우저 테스트에 포함.

## 2026-11-21 — kg 원재료 입출고일지
- 기존 재고 관리에 원재료 입출고일지 추가. kg 입고·사용·실사, 기존 실사 및 생산 차감 내역, 현재 kg 잔량을 한곳에서 조회.
- 이미 만든 완제품의 예약 제외 수량과 재료로 추가 생산 가능한 수량을 별도 표시. 기존 재고 저장, 예약 및 레시피 계산을 재사용. DB 스키마, 주문 데이터 및 개수 단위 변경 없음.

## 2026-11-21 — 레시피 관리 화면
- 제품·반제품의 배합표와 확정 상태, 원재료 목록을 분리해서 조회. 품목 신규 등록과 레시피 입력을 같은 화면에서 연결.
- 판매상품 등록, 주문 차감, 생산 실사와 별개. 기존 재고 저장 및 레시피 권한을 재사용.

- 입고 엑셀: 등록 품목 자동 반영, 개수·kg 구분, 확정 포장단위 환산, 저장 전 미리보기. 실사 양식 및 기존 출고 재고와 분리.
